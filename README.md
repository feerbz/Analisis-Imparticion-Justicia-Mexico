# Proyecto de Analítica de Datos

## Análisis de películas y series de Netflix

### Descripción del proyecto

Este proyecto consiste en realizar un análisis exploratorio de datos sobre películas y series disponibles en Netflix, con el propósito de identificar tendencias, patrones y relaciones entre diferentes características de los contenidos.

### Objetivo general

Analizar el catálogo de películas y series disponibles en Netflix mediante técnicas de analítica de datos, con el propósito de identificar tendencias, patrones y relaciones entre características como género, año de lanzamiento, país de producción, duración, popularidad y valoración.

### Fuente de datos

El proyecto utilizará un conjunto de datos obtenido de Kaggle que contiene información sobre películas y series disponibles en Netflix, así como información relacionada con actores y directores.
